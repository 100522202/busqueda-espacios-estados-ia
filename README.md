# Búsqueda en Espacios de Estados y Navegación - Inteligencia Artificial (IA)

Práctica de la asignatura **Inteligencia Artificial (UC3M)**.

---

## Descripción

Implementación de algoritmos clásicos de búsqueda en espacios de estados para resolver problemas de navegación en laberintos y grafos cargados dinámicamente desde ficheros **JSON**.

### Algoritmos:
* **Búsqueda Informada:** A* (A-Estrella) con diseño de funciones heurísticas admisibles.
* **Búsqueda No Informada:** BFS (Breadth-First Search) y DFS (Depth-First Search).
* **Análisis de Rendimiento:** Comparación de nodos expandidos, factor de ramificación y coste del camino encontrado.

---

## Uso

```bash
python main.py mapa.json
```
